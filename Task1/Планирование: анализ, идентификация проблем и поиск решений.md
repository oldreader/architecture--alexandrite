### Существующие и потенциальные проблемные места
- Разные профили нагрузки на mes api приложение: оно вычисляет заказы,
отдает заказы. Приложение может медленно отвечать, так как оно выполняет вычистельные задачи по расчёту
- Нет понимания почему медленно загружаются данные по ордерам: из-за нагрузки на БД или из-за  медленной работы mes api. 
- Нет способа понять где застревают заказы - нет механизма трассировки

### Инициативы, которые необходимы для устранения нежелательных ситуаций
1. внедрить мониторинг длa MES API и SHOP API 
2. внедрить трассировку 
3. добавить кэширование в узких местах по результату анализа нагрузки 
4. разделить MES API на read профиль и write профиль. Если это купленное преложение, то можно запустить 
5. Реплика на чтение
