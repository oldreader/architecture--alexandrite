### Что отслеживаем?

Запрос Оператора на расчёт
1 Сценарий 
MES -> MES API-> Message Queue -> CRM API -> Shop DB
              -> MES DB
              -> 3d storage
2 Сценарий
Запрос Оператора на получения заказов 
MES -> MES API-> MES DB
3 Сценарий
Запрос из интернет магазина для клиента по его заказу 
Internet Shop -> Shop API-> Shop DB
                         -> 3d storage

### Мотивация

Отслеживание механизма калькуляции расчёта заказа.
Заказ может выполняться долго по разным причинам - долго читаем из БД, долго вычисляем, долго ждём при постановке в
очереди, долго читаем из очереди, долго пишем в бд магазина. 
На любом этапе может что-то пойти не так и мы сможем понять где заказ отвалился. 

### Предлагаемое решение
1 Сценарий 
MES API и CRM API контекст связываются по идентификатору order id. 
2 Сценарий
Запрос на чтение нет необходимости связывания по контексту - отслеживаем по traceId
3 Сценарий
Запрос на чтение нет необходимости связывания по контексту - отслеживаем по traceId
